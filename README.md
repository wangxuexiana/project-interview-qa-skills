# Project Interview Q&A

基于当前代码仓库自动生成**项目专属技术面试题库**的 Agent Skill。通过分析项目源码生成项目 Wiki 作为中间理解层，再结合代码画像产出中层场景化面试题，帮助候选人准备"项目八股 + 项目追问"。

## 核心能力

- **项目画像分析**：自动扫描代码库，识别项目类型、技术栈、核心模块和风险信号
- **项目 Wiki 生成**：将分析结果转化为结构化的项目理解，包含业务主线、模块评估和风险证据矩阵
- **面试题库生成**：产出 30 道（可定制）结合项目实际的场景化面试题，每道题包含：
  - 考察点
  - 标准详解版（背景、设计目标、项目实现、风险与取舍、可优化方向）
  - 面试表达版（自然口语化的候选人表达）
  - 结合本项目（代码证据关联）
  - 可选追问
- **追问训练模式**：支持深度追问、模拟面试、答案润色、补题和复习路线规划

## 目录结构

```
project-interview-qa-skills/
├── SKILL.md                        # Skill 定义与工作流
├── agents/
│   └── openai.yaml                 # Agent 接口配置
├── references/
│   ├── archetypes.yaml             # 项目类型定义与面试焦点
│   ├── followup-modes.md           # 追问训练模式规范
│   ├── output-contract.md          # 输出格式约定
│   ├── question-rubrics.md         # 题目质量标准
│   ├── signal-rules.yaml           # 代码信号 → 面试角度映射
│   └── wiki-guidelines.md          # Wiki 使用指南
└── scripts/
    ├── analyze_project.py          # 项目分析脚本
    ├── generate_project_wiki.py    # Wiki 生成脚本
    └── validate_question_bank.py   # 题库质量校验脚本
```

## 使用方式

在 Agent 中加载此 Skill 后，直接在对话中使用：

```
# 生成面试题库
帮我基于当前项目生成 30 道面试题

# 追问训练
展开 Q7             # 对第 7 题进行多层追问
模拟 订单模块 面试    # 模拟面试官一问一答
优化 Q12 答案        # 将答案润色为更自然的表达
补 10 道 支付 题     # 追加特定模块的题目
给我复习路线          # 按重要性安排准备顺序
```

## 项目类型覆盖

支持 8 种项目类型的自动识别与针对性质问策略：

| 类型 | 面试焦点 |
|------|---------|
| 交易型电商/教育销售 | 高并发、幂等、库存扣减、支付回调、补偿 |
| 学习/内容/媒体平台 | 发布流程、进度追踪、延迟写入、搜索同步 |
| SaaS/后台/工作流 | RBAC/ABAC、租户隔离、审批状态机、审计 |
| 社交/消息/协作 | 消息投递、未读计数、排序、去重、扩散 |
| 数据/分析/AI | 数据流、Schema 演化、模型推理、可观测性 |
| 基础设施/开发者工具 | 扩展边界、配置优先级、故障恢复、安全 |
| 前端/移动端产品 | 组件设计、状态流、API 缓存、错误处理 |
| 游戏/交互工具 | 游戏循环、状态一致性、渲染架构、性能 |

## 技术栈
